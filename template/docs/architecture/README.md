# Architecture

Put durable architecture references here — diagrams, component/module maps,
data-flow notes, or a lightweight ADR-style log of structural decisions that
outlive any single issue.

This folder is intentionally empty in the template. It exists so an adopting
project has an obvious, agreed-upon place to put this material from day one,
instead of each contributor inventing their own location. Keep entries
technology-neutral in spirit — describe what the pieces are and how they relate,
not implementation detail that belongs in the code itself.
